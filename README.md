**Retail Sales SQL Assessment**



1. **Project Overview**



&nbsp;	This project analyses retail sales data for October 2026 using SQL. It focuses on data cleaning, sales calculations, product returns, regional performance, and store-level analysis.



**2. Tools and Technologies**



* **Platform:** SQL Server Management Studio (SSMS)
* **Database Engine:** Microsoft SQL Server
* **Query Language:** SQL



**3. Files Included**

* **SQL/**– SQL queries used for the assessment.
* **Documents/**– Completed Word assessment worksheet.
* **Screenshots/**– Query execution results.
* **ER\_Diagram/**– Retail database ER diagram.
* **Presentation/**– PowerPoint findings and recommendations.



**4. Assessment Tasks**



* Created the six starter tables.
* Loaded the provided retail datasets.
* Checked the total number of records in each table.
* Performed data cleaning and duplicate handling.
* Calculated gross sales, return values and net sales.
* Compared regional sales performance.
* Analysed store performance and product category returns.
* Prepared the retail ER diagram.
* Summarised findings and recommendations.



**4. Reporting Period**

October 1–31, 2026.
